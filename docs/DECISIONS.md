# Decisions

- 2026-11-17: Use a new monorepo scaffold because the repository was empty; use SQLite only for direct local API development while Compose uses PostGIS-backed PostgreSQL.
- 2026-11-17: Use append-only signed ULID events; sync acknowledgements are idempotent by event ID. Browser key material is persisted in IndexedDB for reload continuity.
- 2026-11-17: Signature canonicalization covers every envelope field except `signature`, matching the event-envelope definition. Mesh hop mutation is a later M3 protocol migration.
- 2026-11-17: Pin the current Node LTS and latest stable compatible Python/JavaScript libraries. Add explicit Vite and Workbox `glob` overrides because the latest plugin lock otherwise selected versions covered by current npm audit advisories.
- 2026-11-17: Keep a worker process in M0 so the service topology is present; asynchronous triage work begins in M2.
- 2026-11-17: M1's local media route caps upload size and returns content-derived IDs. Durable object storage, resumable chunks, content scanning, auth ownership, and server-side media persistence are deferred to hardening.
- 2026-11-17: M1 supports GPS, last-known coordinates, and manual coordinate entry. A cached offline basemap for selecting a visual pin is deferred because no offline tile source was supplied.
- 2026-11-17: Docker was unavailable in the initial restricted shell. Approved Docker daemon access was later enabled; Compose build, health, dashboard, and offline browser checks are now run directly.
- 2026-11-17: The package registry was initially unreachable in the restricted shell. Package installation succeeded after using the approved package-manager path, and both npm and Python lockfiles are generated from exact pins.
- 2026-11-17: A deterministic generated-set fallback keeps local protocol-law tests usable if Hypothesis cannot be installed; CI installs Hypothesis and runs its property-based cases.
- 2026-11-17: Docker's npm 11 clean install rejected a lock generated on Windows because it omitted foreign-platform optional packages (Lightning CSS and Rolldown). Use lockfile-aware `npm install --include=optional` in Linux image builds and CI to materialize the platform packages; this preserves locked versions while avoiding npm's cross-platform `npm ci` validation failure.
- 2026-11-17: TypeScript 7 needs its OS-specific native compiler package. Pin the Linux x64 package as an optional root dependency so it is represented in the cross-platform lockfile; use Debian slim for the build stage to provide a glibc Linux runtime.
- 2026-11-17: Keep the Linux x64 GNU Rollup, Rolldown, and Lightning CSS bindings as explicit optional root dependencies too. npm on Windows omitted these entries from the lockfile even though Linux image builds need them.
- 2026-11-17: M2 projects immutable events through a Celery worker and Redis stream. When Redis is absent in local tests, operator mutations replay synchronously to preserve deterministic coverage.
- 2026-11-17: Duplicate text matching uses deterministic character n-gram cosine as the offline multilingual fallback until a licensed embedding model is configured; the scoring weight and hard distance/device rules remain explicit.
- 2026-11-17: Translation remains pluggable and does not invent English text when an offline translation model is unavailable; original-language text and language tag are retained.
- 2026-11-17: Routing uses a straight-line estimate with a visible warning until an offline road graph is supplied; road confidence is still time-decayed for operator context.
- 2026-11-17: The coordinator dashboard is hosted at `/dashboard`; Nginx history fallback serves the SPA on direct navigation.
- 2026-11-17: M2 migration uses SQLAlchemy metadata to create the initial schema, while Alembic provides the versioned deployment entry point. PostGIS geometry and production schema evolution remain M4 hardening.
- 2026-11-17: M3 relays preserve original signed event bytes and keep hop/TTL counters in an outer transport frame because mutating signed hops would invalidate Ed25519 signatures. Android physical-device acceptance is represented by the spec-approved 100-node simulator in this environment.
- 2026-11-17: M4 uses synthetic H3 risk cells because no licensed public hazard or basemap dataset was supplied. Household PII is encrypted before persistence; production must configure and securely back up a registry key.
- 2026-11-17: The risk score weights hazard exposure 40%, population density 20%, vulnerable-household density 25%, and access difficulty 15%; this is a transparent demo index, not an official forecast.
- 2026-11-17: M4 simulation reports use three named synthetic scenarios with ten independent seeds each. k6 measures authenticated incident reads; its output is a local deployment measurement, not a service-level guarantee.
- 2026-11-18: Local k6 read load passes at 25 VUs (8,204 requests, 102.4 req/s, p95 274 ms, 0% failures); 100 VUs exceeds the local container capacity (about 31 req/s, p95 695 ms, 2.34% failures). Preserve both measurements as capacity evidence rather than weakening thresholds.
- 2026-11-18: Household privacy operations export decrypted registration data only through a coordinator/admin endpoint and record field names, never contact values, in the audit log. Deletion physically removes the encrypted record and retains only its coarse H3 cell in the audit trail. Registrar and explicit consent timestamps are stored as metadata.
- 2026-11-18: Sender follow-ups use signed `sos.ping` events with the original request ID and share the durable browser outbox with SOS events, so “still need help” and “we are safe” can be queued offline and replayed idempotently.
- 2026-11-18: Household coverage visualizations aggregate by H3 resolution 8 and return only cell centroids and counts. Exact registered coordinates remain encrypted and are available only in the coordinator household export.
- 2026-11-18: Volunteer assignment reads are scoped to the volunteer's team; coordinator/admin field views may inspect all assignments. Field responses include only incident routing and response fields needed to act on the assignment.
- 2026-11-18: Volunteer field mode caches assignment cards locally and queues status updates while offline; queued status changes replay when connectivity returns. Third-party map navigation is an optional online link, while coordinates remain visible for offline field use.
- 2026-11-18: M4 simulation models three seeded connectivity approaches and scales with 500, 5,000, and 20,000 phones. It emits reproducible synthetic comparisons; connectivity and workload rates are scenario assumptions, not field-calibrated claims.
