# M0 foundation demo

1. Run `docker compose -f infra/docker-compose.yml up --build`.
2. Open `http://localhost:4173` for the field client, `http://localhost:8000/health` for API health, and `http://localhost:8000/docs` for OpenAPI.
3. Run `python -m pytest packages/protocol/python services/api` and `npm test --workspace @lifeline/protocol` for protocol and API checks.

All sample inputs in this repository are synthetic.
