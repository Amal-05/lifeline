# M1 offline SOS demo

1. Start the stack using `docker compose -f infra/docker-compose.yml up --build`.
2. Open `http://localhost:4173`, select a language, and submit an SOS.
3. In browser developer tools, select Network > Offline, create another request, and reload to confirm it remains queued.
4. Restore the network. The client resends the stable signed event ID and marks it received after server acknowledgement.
5. Run `npm run test:e2e --workspace @lifeline/web` for the offline reload and reconnect path.

All sample inputs are synthetic. The local demo is not intended for real incident data.
