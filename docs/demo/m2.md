# M2 operations demo

1. Start services: `docker compose -f infra/docker-compose.yml up --build`.
2. Open `http://localhost:4173/dashboard` and sign in with the synthetic local demo coordinator from `.env.example`.
3. Submit synthetic SOS requests through `http://localhost:4173`; use the coordinates and notes in the M2 simulator to exercise duplicate and review paths.
4. Dashboard incidents update through the Redis stream WebSocket. Urgency explanations are included in each incident row. Merge review, audit, assignments, road reports, and exports are available at `/docs` under `/api/v1`.
5. Run `python -m pytest -q`, `npm run test --workspace @lifeline/web`, and `npm run test:e2e --workspace @lifeline/web`.

The local seed credentials and all demo records are synthetic. Change credentials and JWT key before any shared deployment.
